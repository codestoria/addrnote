# 值类别与引用

## 导读

大多数教程直接从右值引用和 `std::move` 开始讲解，这很容易形成一个根深蒂固的误区：

> 右值引用的作用是移动对象。

这个说法颠倒了因果关系。
**值类别是底层规则，引用绑定是约束，移动语义与完美转发是上层能力。**

C++ 中每一条表达式都拥有两个互相独立的属性：

1. **类型（type）**：表达式所代表数据的静态类型
2. **值类别（value category）**：表达式的分类，决定它可以绑定到哪一类引用

本主题的逻辑链条：

1. 表达式分为 lvalue / prvalue / xvalue / glvalue / rvalue；
2. 不同值类别遵循各自的引用绑定规则；
3. C++11 引入右值引用 `T&&`，支持移动构造与移动赋值——也就是移动语义；
4. 模板实参推导结合引用折叠，产生转发引用；
5. `std::forward` 保留表达式原始的值类别，实现完美转发。
