# Addrnote 开发文档

本目录面向 Addrnote 的维护者。首次运行项目请先看[快速开始](../README.md#快速开始)；按任务选择下面的指南。

- [内容、分类与语言](content-and-i18n.md)：添加笔记、分类及翻译，理解目录编号。
- [开发、检查与部署](development-and-deployment.md)：安装、常用命令、排错及 GitHub Pages 部署。
- [项目结构和数据流](architecture.md)：查找文件职责，理解侧边栏生成流程。
- [主题与布局](theme-and-layout.md)：调整外观、组件和页面布局。

站点文档的源目录是 `notes/`，不是本目录。`docs/` 存放仓库维护文档，不会自动成为站点页面。
